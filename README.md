

# HR Employee Attrition Analysis

## Project Overview

This project focuses on analysing employee attrition data to understand workforce patterns and explore factors associated with employee turnover.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL

## Project Workflow

1. Import employee data.
2. Clean and preprocess the dataset using Pandas.
3. Perform exploratory data analysis.
4. Analyse employee attrition patterns.
5. Explore attrition across departments, age groups and other available employee attributes.
6. Create visualizations using Matplotlib.
7. Summarize findings and insights.

## Project Objectives

- Understand employee attrition patterns.
- Explore workforce demographics.
- Analyse employee turnover across available categories.
- Identify patterns that may be associated with attrition.
- Present findings through data visualizations.

## Tools & Skills Demonstrated

Python | Pandas | NumPy | Matplotlib | Data Cleaning | Data Analysis | Data Visualization
